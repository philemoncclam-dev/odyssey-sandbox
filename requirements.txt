# The lineage engine's dependencies. Not the application's — Odyssey's app is
# the browser bundle under app/ and needs none of this.
#
# The list is short because the engine is pure: dropping router.py removed the
# FastAPI adapter and with it fastapi, uvicorn, httpx, azure-identity,
# anthropic, openai and psycopg.

# The run request/result contract. protocol.py is the schema.
pydantic>=2.11

# Column-level lineage from SQL text, for the stub engine — the one that runs
# without a JVM, and therefore the one CI exercises. Import-guarded in
# _sqllineage.py: a missing sqlglot degrades the run rather than crashing it.
#
# The `databricks` dialect is used, not `spark` — see the note in
# _sqllineage.py. Spark 4.x VARIANT path access (`payload:user.id`) is a parse
# error in the latter and `analyze` degrades silently, so a table vanishes from
# the graph with nothing said.
sqlglot>=25.0

# Tests
pytest>=8.3

#   openlineage-python
